# 嵌套卡片工作流编排设计文档

## 设计目标

嵌套卡片工作流编排系统旨在通过全新的交互设计，为用户提供更加直观、易用的智能体工作流编排体验。这种设计完全抛弃了传统流程图的复杂性，转而采用一种层级化、组件化的卡片结构，让用户可以更加专注于功能配置而非布局排版。

## 核心设计理念

### 整体卡片结构

系统采用单一大卡片作为容器，内部嵌套多个功能模块卡片。这种设计有以下优势：

1. **视觉统一性**：所有功能组件在一个统一的容器内展示，提供一致的视觉体验
2. **层次结构清晰**：通过视觉层级和连接线，清晰表达模块间的执行顺序和关系
3. **专注于配置**：用户可以专注于每个功能模块的配置，而不必担心布局问题
4. **降低认知负担**：相比复杂的流程图，卡片结构更容易理解和操作

### 功能模块分类

系统按照功能类型将工具分为四大类：

1. **检索增强模块**（蓝色）：整合知识库检索和联网搜索等信息获取工具
2. **文本处理模块**（绿色）：提供文本分析、翻译、摘要等处理能力
3. **数据分析模块**（橙色）：提供数据计算、统计和可视化等分析功能
4. **内容生成模块**（紫色）：负责文本生成、图像创建等内容创作功能

每个模块都有独特的颜色标识，帮助用户在视觉上快速区分不同功能类别。

## 交互设计

### 模块卡片

每个功能模块卡片具有以下特性：

1. **可折叠设计**：点击卡片头部可展开/折叠详细配置区域
2. **状态指示**：卡片头部显示已选工具和知识库数量
3. **视觉连接**：卡片间通过虚线连接，表示执行顺序和数据流向
4. **色彩编码**：每类功能模块都有独特的颜色主题，增强视觉识别

### 配置界面

模块展开后的配置界面包含：

1. **执行策略选择**：串行、并行或条件执行的策略选项
2. **工具选择区**：通过点击选择/取消该模块要使用的工具
3. **知识库选择区**：通过点击选择/取消该模块要使用的知识库
4. **高级配置区**：设置超时时间、重试次数等高级参数

### 扩展性

系统提供"添加功能层级"按钮，允许用户根据需要添加更多自定义模块，满足复杂场景的需求。

## 色彩系统

色彩是界面设计的重要元素，每种功能模块都有专属的色彩标识：

- **检索增强模块**：蓝色系 (#1976d2)，象征信息和知识
- **文本处理模块**：绿色系 (#388e3c)，象征处理和转化
- **数据分析模块**：橙色系 (#f57c00)，象征洞察和分析
- **内容生成模块**：紫色系 (#7b1fa2)，象征创造和想象

每个模块的颜色应用于卡片边框、图标背景和选中状态，形成一致的视觉语言。

## 技术实现

系统主要包含两个核心组件：

1. **ToolOrchestrationStep**：作为容器组件，负责整体布局和管理
2. **NestedCardOrchestration**：实现嵌套卡片的核心逻辑，包括：
   - 卡片展开/折叠状态管理
   - 工具和知识库选择逻辑
   - 模块间数据传递
   - 配置数据的收集和提交

每个功能模块内部使用 Material-UI 的 Card、Collapse 等组件实现可折叠的卡片效果，通过状态管理实现工具和知识库的选择功能。

## 用户体验优化

1. **动画过渡**：添加卡片展开/折叠的平滑动画，增强交互体验
2. **视觉反馈**：选中/取消工具时提供明确的视觉反馈
3. **空状态处理**：当没有可用工具或知识库时显示友好的提示
4. **连接线动效**：虚线连接可以考虑添加动画效果，强化数据流向感

## 与传统流程图的对比

| 特性 | 嵌套卡片编排 | 传统流程图 |
|------|-------------|----------|
| 学习曲线 | 低，直观易懂 | 高，需要理解流程图概念 |
| 布局复杂度 | 低，自动布局 | 高，需手动排列节点 |
| 配置专注度 | 高，聚焦于功能 | 分散，需兼顾布局和功能 |
| 扩展能力 | 中等，固定结构 | 高，自由度大 |
| 适用场景 | 标准工作流程 | 复杂分支流程 |

## 未来改进方向

1. **模板系统**：提供常用的工作流模板，让用户可以快速开始
2. **拖放排序**：允许用户通过拖放调整模块执行顺序
3. **条件分支**：增强条件执行能力，支持更复杂的逻辑判断
4. **预览模式**：提供工作流执行预览，帮助用户理解执行过程
5. **响应式设计**：优化在不同屏幕尺寸下的显示效果

## 总结

嵌套卡片工作流编排系统通过简化交互模型，让工作流编排变得更加直观和高效。它专注于功能配置而非复杂布局，帮助用户快速构建智能体工作流，是对传统流程图编排方式的一次创新尝试。
