# 🖥️ 智能体编排器全屏模式使用指南

## ✨ 功能概述

智能体编排器现在支持全屏模式，为您提供更大的设计空间和更专业的工作体验。

## 🚀 如何使用

### 进入全屏模式
1. **点击全屏按钮**：在页面右上角找到全屏图标按钮
2. **键盘快捷键**：按 `F11` 键快速切换全屏
3. **自动优化**：进入全屏后界面会自动调整为最佳布局

### 退出全屏模式
1. **点击退出按钮**：点击右上角的退出全屏按钮
2. **键盘快捷键**：按 `ESC` 或 `F11` 键退出
3. **自动恢复**：退出后界面会恢复到原始状态
