# 🧩 基于功能模块的智能体编排系统

## ✨ 设计理念

根据用户的建议，我们重新设计了智能体编排系统，采用**功能模块化**的设计理念。将相似功能的工具和服务归类到同一个功能模块中，每个模块内部可以进行细粒度的配置和策略设置。

## 🎯 核心优势

### 1. 功能导向的分类
- **逻辑清晰**：按功能而非工具类型进行分类
- **业务对齐**：模块设计与实际业务场景对应
- **易于理解**：用户可以直接理解每个模块的作用

### 2. 模块内部灵活配置
- **执行策略**：支持串行、并行、优先级、故障转移等多种策略
- **条件控制**：可以设置模块的启用和跳过条件
- **参数调节**：超时时间、重试次数等可精细调节

### 3. 智能推荐和自动归类
- **工具推荐**：根据模块类型自动推荐相关工具
- **自动分类**：新添加的工具自动归类到合适的模块
- **配置建议**：基于最佳实践提供配置建议

## 🧩 功能模块分类

### 1. 检索增强模块 (Retrieval Augmentation)
**功能定位**：整合各种信息检索能力
- **本地知识库检索**：向量数据库、文档库检索
- **联网搜索**：搜索引擎、实时信息获取
- **API数据获取**：第三方数据接口调用

**配置选项**：
- 执行策略：串行（依次尝试）、并行（同时检索）、混合（智能选择）
- 检索优先级：知识库优先 → 联网搜索 → API接口
- 结果合并：摘要合并、完整拼接、最佳选择
- 故障转移：知识库失败时自动切换到联网搜索

**使用场景**：
```
问题：如何制作咖啡？
执行流程：
1. 本地知识库检索咖啡制作方法
2. 并行联网搜索最新咖啡技巧
3. 合并结果，提供全面答案
```

### 2. 文本处理模块 (Text Processing)
**功能定位**：各种文本分析和处理任务
- **文本分析**：情感分析、关键词提取、摘要生成
- **语言处理**：翻译、语法检查、格式转换
- **内容优化**：改写、润色、风格调整

**配置选项**：
- 处理链：定义文本处理的先后顺序
- 质量控制：设置处理质量阈值
- 语言配置：源语言、目标语言设置
- 输出格式：Markdown、HTML、纯文本

**使用场景**：
```
任务：处理英文文档
执行流程：
1. 英译中翻译
2. 提取关键词
3. 生成摘要
4. 格式化输出
```

### 3. 数据分析模块 (Data Analysis)
**功能定位**：数据计算、分析和可视化
- **数据计算**：统计计算、数学运算、数据聚合
- **趋势分析**：时间序列分析、预测建模
- **可视化**：图表生成、报表制作

**配置选项**：
- 计算精度：设置数值计算精度
- 分析深度：简单统计 vs 深度分析
- 图表类型：柱状图、折线图、饼图等
- 结果展示：数据表格、可视化图表

### 4. 内容生成模块 (Content Generation)
**功能定位**：各种内容创作和生成
- **文本生成**：文章写作、报告生成、创意文案
- **图像生成**：AI绘画、图表制作、图像编辑
- **多媒体**：音频合成、视频制作

**配置选项**：
- 创作风格：正式、活泼、专业、创意
- 输出长度：短文、长文、详细报告
- 质量级别：快速生成 vs 精细制作
- 版权控制：原创内容、引用标注

### 5. 多模态处理模块 (Multimodal Processing)
**功能定位**：处理图像、音频、视频等多媒体内容
- **图像处理**：识别、分析、编辑、生成
- **音频处理**：语音识别、音频分析、合成
- **视频处理**：视频分析、剪辑、字幕生成

**配置选项**：
- 处理质量：高质量 vs 快速处理
- 输出格式：不同的文件格式选择
- 压缩比例：文件大小与质量平衡
- 功能组合：多种处理功能的组合使用

### 6. 外部集成模块 (External Integration)
**功能定位**：与外部系统和服务的集成
- **API调用**：第三方服务接口
- **数据库操作**：读取、写入、更新数据
- **文件系统**：文件读写、云存储操作
- **消息通知**：邮件、短信、推送通知

**配置选项**：
- 认证方式：API Key、OAuth、Token
- 超时设置：请求超时时间
- 重试策略：失败重试次数和间隔
- 数据格式：JSON、XML、CSV等

### 7. 流程控制模块 (Workflow Control)
**功能定位**：控制整个智能体的执行流程
- **条件判断**：基于结果的分支选择
- **循环控制**：重复执行某些模块
- **错误处理**：异常情况的处理机制
- **状态管理**：执行状态的跟踪和控制

**配置选项**：
- 判断条件：设置分支判断的条件
- 循环次数：最大循环次数限制
- 错误策略：忽略、重试、终止
- 状态保存：执行状态的持久化

## 🔧 模块配置界面

### 检索增强模块配置示例

```typescript
interface RetrievalAugmentationConfig {
  // 基础设置
  enabled: boolean;
  priority: number;
  
  // 检索源配置
  knowledgeBases: {
    enabled: boolean;
    databases: KnowledgeBase[];
    searchStrategy: 'semantic' | 'keyword' | 'hybrid';
    maxResults: number;
  };
  
  // 联网搜索配置
  webSearch: {
    enabled: boolean;
    searchEngine: 'google' | 'bing' | 'duckduckgo';
    maxResults: number;
    safeguard: boolean;
  };
  
  // 执行策略
  executionStrategy: 'sequential' | 'parallel' | 'hybrid';
  
  // 结果处理
  resultMerging: {
    strategy: 'summarize' | 'concat' | 'best';
    maxLength: number;
    duplicateRemoval: boolean;
  };
  
  // 故障转移
  fallbackChain: string[]; // ['knowledgeBase', 'webSearch', 'apiCall']
}
```

1. **分组展示**：每个模块独立展示，可折叠/展开
2. **拖拽配置**：工具和知识库可以拖拽到对应模块
3. **策略选择**：下拉菜单选择执行策略
4. **参数调节**：滑块调节超时、重试等参数
5. **预览效果**：实时预览模块配置效果

## 新增抽屉式布局模式

为了提供更加简洁、直观的工作流设计体验，我们实现了一种全新的抽屉式容器布局模式，该模式具有以下特点和优势：

### 抽屉式布局的设计理念

抽屉式布局抛弃了传统流程图的复杂性，采用了更符合用户直觉的上下堆叠式设计：

1. **线性流程表达**：通过上下堆叠的抽屉卡片，清晰表达工作流的执行顺序
2. **简化空间关系**：无需处理复杂的节点位置和连线问题
3. **聚焦于配置**：用户可以专注于各模块的功能配置，而非布局调整
4. **直观的信息展示**：重要信息直接显示在抽屉卡片上，无需展开查看

### 实现方案

抽屉式布局的核心组件包括：

1. **抽屉容器**：使用 Material-UI 的 Paper 组件实现，支持展开/折叠操作
2. **模块类型区分**：
   - 每种功能模块都有其独特的颜色系统
   - 检索增强模块：蓝色系
   - 文本处理模块：绿色系
   - 数据分析模块：橙色系
   - 内容生成模块：紫色系

3. **信息层级设计**：
   - 抽屉头部：显示模块类型、名称和配置状态概览
   - 抽屉内容区：提供工具和知识库的选择界面
   - 工具/知识库标签：已选择项目高亮显示

4. **模式切换**：
   - 提供"画布模式"和"抽屉模式"的便捷切换
   - 保存两种模式下的配置，确保无缝衔接

### 用户交互优化

1. **展开/折叠操作**：点击抽屉头部可展开或折叠内容区
2. **工具选择**：点击工具/知识库标签可切换选择状态
3. **视觉反馈**：
   - 选中项目有明显的高亮效果
   - 未选中项目呈现灰色半透明状态
   - 抽屉头部颜色与模块类型一致

## 拖拽体验优化

为了提供更流畅的拖拽体验，我们重新实现了拖拽功能：

### 问题分析

原有基于HTML5拖放API的实现存在以下问题：

1. 拖拽过程中有明显的延迟感
2. 拖动时不跟手，用户体验较差
3. 拖放过程中的视觉反馈不足

### 解决方案

我们采用了基于原生MouseEvent的拖拽实现：

1. **原生鼠标事件**：
   - 使用 `mousedown`、`mousemove` 和 `mouseup` 事件
   - 实时计算并更新节点位置

2. **状态管理**：
   - 使用 `draggedNodeId` 跟踪当前拖拽的节点
   - 使用 `isDragging` 控制拖拽状态相关UI
   - 使用 `dragOffset` 保存鼠标相对节点的偏移量

3. **实时更新**：
   - 在 `mousemove` 事件中实时更新节点位置
   - 提供流畅的跟手体验

4. **视觉反馈**：
   - 拖拽过程中显示提示信息
   - 画布边框高亮显示
   - 背景颜色微妙变化提供状态感知

5. **边界处理**：
   - 防止节点被拖出画布
   - 考虑画布滚动位置

这一实现极大地提升了拖拽的流畅度和用户体验，使得节点移动感觉更加自然和直观。

## 对比分析

### 传统画布式流程图

优点：
- 自由度高，可以任意排布节点
- 可以直观表达复杂的分支和合并逻辑
- 符合传统工作流设计的思维习惯

缺点：
- 对于简单任务过于复杂
- 需要处理节点位置和连线问题
- 布局调整分散了对功能配置的注意力

### 抽屉式布局

优点：
- 简洁直观，易于理解
- 专注于功能配置而非布局
- 操作简单，学习成本低
- 适合移动设备使用

缺点：
- 表达复杂分支逻辑能力较弱
- 自由度相对较低
- 不符合某些用户的工作流思维模式

## 最佳实践建议

1. **简单顺序流程**：优先使用抽屉式布局
2. **复杂分支流程**：优先使用画布式布局
3. **初学者用户**：建议从抽屉式布局开始
4. **高级用户**：可以根据任务复杂度灵活切换两种模式

通过提供这两种互补的布局模式，我们能够满足不同用户的需求和偏好，提供更加灵活和强大的工作流设计体验。
