# typescript-standards

## Description

TypeScript类型定义和使用的最佳实践，提高代码质量和安全性

## Content

使用本规则确保TypeScript代码符合以下类型标准:

### 类型定义显式化
- 禁止使用any类型，应当:
  - 使用明确的类型定义
  - 必要时使用泛型
  - 无法确定类型时使用unknown而非any
- 为所有变量和函数返回值定义明确类型

### 接口命名规范
- 接口命名遵循以下规则:
  - 使用大驼峰命名法(PascalCase)
  - 避免使用I前缀(如IProps)
  - 接口名应清晰表达其用途
- 避免过于抽象或泛泛的接口名称

### 函数参数和返回值类型
- 函数定义应当:
  - 显式声明所有参数的类型
  - 显式声明返回值类型
  - 对于泛型函数，确保约束合理
- 避免使用Function类型，使用具体的函数类型签名

### 类型组合而非继承
- 遵循组合优于继承的原则:
  - 使用交叉类型(&)组合多个类型
  - 使用Partial<T>, Pick<T, K>, Omit<T, K>等工具类型
  - 避免过深的继承层次
- 使用联合类型(|)表达多种可能类型

### 导出类型声明
- 类型声明的导出规则:
  - 共享的类型定义应放在一个集中的类型文件中
  - 明确导出需要被其他模块使用的类型
  - 考虑使用命名空间组织相关类型
- 重要的类型应有文档注释
