# 🎯 基于模板的智能体编排系统使用指南

## ✨ 设计理念

全新的智能体编排系统采用**预置模板 + 工具热插拔**的设计理念，让用户无需从零开始绘制复杂的流程图，而是基于经过验证的流程模板进行快速配置。

## 🚀 核心优势

### 1. 降低使用门槛
- **无需连线**：告别复杂的节点连线操作
- **预置流程**：基于最佳实践的流程模板
- **拖拽配置**：简单的拖拽即可配置工具和知识库
- **即插即用**：工具和知识库支持热插拔

### 2. 提高设计效率
- **快速启动**：选择模板即可开始配置
- **智能推荐**：每个模板都有推荐的工具和知识库
- **可视化流程**：清晰的流程图展示执行逻辑
- **实时预览**：配置变更实时反映在界面上

### 3. 保证流程质量
- **经过验证**：所有模板都基于成熟的执行模式
- **逻辑清晰**：预定义的连接关系确保流程合理性
- **错误预防**：避免用户创建不合理的流程结构

## 📋 预置流程模板

### 1. 串行执行流程 (Sequential)
```
知识检索 → 工具执行1 → 工具执行2 → 结果汇总
```
- **适用场景**：有依赖关系的任务处理
- **特点**：按顺序执行，前一步的输出作为后一步的输入
- **推荐工具**：搜索、分析、总结类工具

### 2. 并行执行流程 (Parallel)
```
知识检索 → 并行工具组 → 结果合并
           ├─ 工具A
           ├─ 工具B
           └─ 工具C
```
- **适用场景**：独立任务的并行处理
- **特点**：多个工具同时执行，提高处理效率
- **推荐工具**：翻译、分析、验证等独立工具

### 3. 混合执行流程 (Hybrid)
```
初始检索 → 决策分支 ┬─ 并行处理 ┐
                   └─ 单一工具 ┘ → 结果整合
```
- **适用场景**：复杂的条件分支处理
- **特点**：结合串行和并行，支持条件判断
- **推荐工具**：分析、处理、验证、转换类工具

## 🎨 界面功能详解

### 左侧面板
1. **流程模板**：选择预置的流程模板
2. **可用工具**：拖拽工具到流程步骤中
3. **知识库**：拖拽知识库到相应步骤

### 右侧画布
1. **流程可视化**：显示完整的执行流程
2. **连接线**：自动生成的流程连接关系
3. **步骤配置**：点击步骤进行详细配置

### 交互操作
1. **选择模板**：点击左侧模板进行选择
2. **拖拽配置**：将工具/知识库拖拽到步骤上
3. **启用/禁用**：通过开关控制步骤是否执行
4. **编辑配置**：点击步骤查看和编辑详细配置

## 🔧 操作流程

### 第一步：选择模板
1. 在左侧面板选择合适的流程模板
2. 画布会显示完整的流程结构
3. 每个步骤都有明确的功能定义

### 第二步：配置工具
1. 从左侧工具列表拖拽工具到相应步骤
2. 支持一个步骤配置多个工具
3. 可以随时添加或移除工具

### 第三步：配置知识库
1. 将知识库拖拽到知识检索步骤
2. 支持多知识库并行或串行查询
3. 根据需要调整知识库优先级

### 第四步：调整配置
1. 点击步骤查看配置详情
2. 启用或禁用特定步骤
3. 调整执行模式（串行/并行）

### 第五步：完成创建
1. 检查流程配置的完整性
2. 确认所有必需步骤都已配置
3. 点击"完成创建"生成智能体

## 🎯 步骤类型说明

### 知识查询 (Knowledge Query)
- **功能**：从知识库中检索相关信息
- **配置**：选择知识库，设置查询模式
- **输出**：结构化的知识内容

### 工具执行 (Tool Execution)
- **功能**：执行特定的工具功能
- **配置**：选择工具，设置执行参数
- **输出**：工具处理结果

### 并行组 (Parallel Group)
- **功能**：多个工具并行执行
- **配置**：设置并发数量，选择工具集合
- **输出**：所有工具的执行结果

### 决策点 (Decision Point)
- **功能**：根据条件选择执行路径
- **配置**：设置判断条件和分支逻辑
- **输出**：路由到不同的执行分支

### 合并点 (Merge Point)
- **功能**：汇总多个分支的执行结果
- **配置**：设置合并策略和输出格式
- **输出**：整合后的最终结果

## 🔄 工具热插拔机制

### 添加工具
1. **拖拽添加**：直接拖拽到步骤上
2. **自动去重**：相同工具不会重复添加
3. **即时生效**：配置立即反映在界面上

### 移除工具
1. **编辑界面**：在步骤编辑对话框中移除
2. **批量操作**：支持批量选择和移除
3. **安全检查**：移除前确认不影响流程完整性

### 工具替换
1. **直接替换**：拖拽新工具覆盖旧工具
2. **配置保持**：尽可能保持原有配置参数
3. **兼容性检查**：确保新工具与流程兼容

## 💡 最佳实践

### 模板选择
1. **简单任务**：优先选择串行流程
2. **独立任务**：选择并行流程提高效率
3. **复杂逻辑**：使用混合流程处理条件分支

### 工具配置
1. **功能互补**：选择功能互补的工具组合
2. **性能考虑**：避免在并行组中配置过多工具
3. **依赖关系**：确保工具间的输入输出匹配

### 知识库配置
1. **相关性**：选择与任务相关的知识库
2. **覆盖面**：平衡知识库的广度和深度
3. **更新频率**：考虑知识库的时效性
